# churn: Telco customer churn prediction

Predicts which customers are likely to cancel: validated data, reproducible training, an MLflow registry with dev → staging → prod aliases, a quality gate, model cards, a FastAPI service, Feast and drift-triggered retraining.

**Documentation:** [https://bllsdclsz.github.io/mlops-llmops-platform/churn/](https://bllsdclsz.github.io/mlops-llmops-platform/churn/) (source: [`docs/churn/`](../docs/churn/))
