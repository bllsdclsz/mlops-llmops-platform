# support-rag: multilingual customer-support assistant

A retrieval-augmented support assistant answering in German, French, Italian and English from a help center, with cited answers from a local LLM, guardrails, evaluation gates, tracing and human approval for actions.

> The operator "Nordalp Mobile" and all its help articles, prices and URLs (`*.nordalp.example`) are fictional, written for this project.

**Documentation:** [https://bllsdclsz.github.io/mlops-llmops-platform/support-rag/](https://bllsdclsz.github.io/mlops-llmops-platform/support-rag/) (source: [`docs/support-rag/`](../docs/support-rag/))

```bash
uv run rag --help
```
